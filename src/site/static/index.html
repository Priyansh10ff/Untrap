How it works

Four layers, cheapest first

Most pages have nothing to check and finish in milliseconds. AI only runs on the few bits that look like orders for an AI.

  1. 1

    Find hidden text

    Comments, display:none, 1px or transparent text, text the same color as its background, off-screen text, meta tags, alt text and invisible Unicode.

    Rules · on device · ~10 ms
  2. 2

    Ask Gemini Nano

    Suspicious snippets are judged by Gemini Nano inside Chrome, through Firebase AI Logic's hybrid inference. Private and free.

    On-device AI
  3. 3

    Second opinion

    When Nano is unsure, or isn't on this computer, Firebase AI Logic sends just that snippet to Gemini in the cloud.

    Cloud AI, only when needed
  4. 4

    Protect everyone

    Confirmed traps go into a shared blocklist in Firestore, so the next person who meets the same trap is protected instantly.

    Shared blocklist

X-ray mode

See exactly what was hidden

Press X-ray and every trap is outlined on the page, with the hidden text, how it was hidden and what it tried to make the AI do.

  • Removed before any AI reads the page
  • Nothing changes for people: hidden text was invisible anyway
  • Visible text is only removed when the AI is sure
  • Undo any time: pause Untrap on a site and the page is restored

Privacy

Your browsing stays on your computer

Untrap was built so it never needs to see your browsing.

Stays on your deviceEvery page you visit, its text, and the first AI check (Gemini Nano).
Sent only when neededA single suspicious snippet, never the page, for a cloud second opinion. You can turn this off.
Shared to protect othersA fingerprint of a confirmed trap, its type and the attacking site. Never your URL history. You can turn this off.

Install

Get Untrap in two minutes

  1. Download untrap-extension.zip from the latest release and unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped folder.
  4. On the welcome page, click Download Gemini Nano for private on-device checks. Without it, Untrap uses cloud AI.
  5. Open the Attack Lab and press X-ray this page in the Untrap popup.
